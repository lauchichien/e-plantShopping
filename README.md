# e-plantShopping

## Paradise Nursery - Online Plant Shopping Application

e-plantShopping is a React-based shopping application for Paradise Nursery. Users can browse different types of houseplants, add plants to their shopping cart, and manage their cart before checkout.

### Features
- Browse houseplants in different categories.
- View plant names, images, and prices.
- Add plants to the shopping cart.
- Increase or decrease plant quantities.
- Remove plants from the shopping cart.
- View the total quantity and cost of selected plants.

### Technologies Used
- React
- JavaScript
- Redux Toolkit
- CSS

### Deployment
The application will be deployed using GitHub Pages.
